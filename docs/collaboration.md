# 協業ガイド

プロジェクトの進捗確認方法・ステージング環境のテスト方法・フィードバックの送り方をまとめたガイドです。
開発者に都度確認しなくても自走して状況把握できることを目的としています。

---

## コードリポジトリ（GitHub）

ソースコードは GitHub のプライベートリポジトリで管理しています。

- リポジトリ URL: https://github.com/wknd-studio/brand-closed-ec
- 閲覧には GitHub アカウントへの招待が必要です。アクセスが必要な方はお知らせください。

---

## 進捗確認（Linear）

タスク管理には **Linear**（`https://linear.app/`）を使用しています。

### 進捗の見方

| ステータス      | 意味                                         |
| --------------- | -------------------------------------------- |
| **Backlog**     | 着手待ち。優先度が決まったら Todo へ移動する |
| **Todo**        | 着手予定。次のスプリントで対応するもの       |
| **In Progress** | 現在開発中                                   |
| **In Review**   | 実装完了・コードレビュー中                   |
| **Done**        | ステージング環境で動作確認済み・完了         |
| **Cancelled**   | 対応しないことが決まったもの                 |

### 確認手順

1. Linear にログイン（招待メールから初回設定済みであること）
2. 左サイドバーの **「BRAND」** プロジェクトを選択
3. **Board ビュー**（カンバン）で全ストーリーの状況を一覧確認できる
4. チケットをクリックすると詳細・コメント・開発メモが確認できる

> チームへの招待は Linear の Settings > Members から行ってください。
> プロジェクトの URL: https://linear.app/wknd-studio/team/BRAND/issues

## ステージング環境

本番環境に影響を与えずに動作確認できる環境です。開発中の機能を実際に操作して確認してください。

### アクセス情報

| 項目                   | 値                                                        |
| ---------------------- | --------------------------------------------------------- |
| URL                    | https://brand-closed-ec-stg.white-night-bb71.workers.dev/ |
| テスト会員アカウント   | **TBD**（Clerk で作成後に共有）                           |
| テスト運営者アカウント | **TBD**（Clerk で作成後に共有）                           |
| Stripe 決済            | テストモード。実際の課金は発生しない                      |

### Stripe テスト決済の方法

ステージング環境では Stripe のテストモードを使用しています。カード情報には以下を使用してください。

| 項目       | 値                              |
| ---------- | ------------------------------- |
| カード番号 | `4242 4242 4242 4242`           |
| 有効期限   | 未来の任意の日付（例: `12/30`） |
| CVC        | 任意の3桁（例: `123`）          |

> 実際のカード情報は絶対に入力しないでください。

### 確認時の注意

- ステージング環境のデータは定期的にリセットされる場合があります
- 本番環境とは別のデータベースを使用しており、ステージングで作成した注文・会員データは本番に影響しません
- 意図しない挙動を発見した場合は、次のセクションの方法でフィードバックをお送りください

## フィードバックの送り方

### バグ・不具合の報告

実際に操作していておかしいと感じた場合は、以下の情報を添えてご連絡ください。

1. **どのページで発生したか**（URL を含めると助かります）
2. **何をしたら発生したか**（操作の手順）
3. **何が起きたか**（スクリーンショットがあると助かります）
4. **何が起きることを期待していたか**

> **TBD**: フィードバックの送付先を決定する（Linear チケットへのコメント / LINE / Google Chat のいずれか）

### 仕様変更・追加要望

Linear のチケットにコメントするか、ミーティングでの口頭確認をお願いします。仕様変更は既存の実装や他のストーリーへの影響を確認してから対応します。

## スプリントの進め方

| タイミング     | 内容                                                                   |
| -------------- | ---------------------------------------------------------------------- |
| スプリント開始 | 今回着手するストーリーを確認。Linear の Todo から In Progress へ移動   |
| スプリント中   | Linear でリアルタイムに進捗を確認できる                                |
| スプリント終了 | ステージング環境でのデモ・動作確認。フィードバックを次スプリントに反映 |

> スプリントの期間・デモの日程は別途合意します。
