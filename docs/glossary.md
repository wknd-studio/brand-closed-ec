# 用語集

顧客・開発者が共通の言葉で会話するための用語定義。  
このドキュメントに載っている言葉は、プロジェクト内で統一して使用する。

---

## 会員・ランク

| 用語                 | 定義                                                                                                                                                             |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **会員**             | 招待コードを使って登録した、このサービスの利用者                                                                                                                 |
| **ランク**           | 会員の契約プラン。7種類（STARTER / BASIC / STANDARD / PRO / ADVANCED / PREMIUM / ENTERPRISE）。名称・料金・仕入れ上限は `service-spec.md` の「会員プラン」を参照 |
| **アップグレード**   | 現在のランクより上位のランクに変更すること                                                                                                                       |
| **ダウングレード**   | 現在のランクより下位のランクに変更すること                                                                                                                       |
| **初期費用**         | ランク登録時に一度だけ発生する費用。金額はランクごとに異なる（`service-spec.md` の「料金・仕入れ上限」参照）                                                     |
| **入会**             | 招待コードを使って会員登録し、サービスを利用できる状態になること                                                                                                 |
| **退会**             | 会員資格を終了し、サービスの利用を停止すること                                                                                                                   |
| **運営者**           | 招待コード発行・会員・商品・注文・在庫を管理するサービス管理者                                                                                                   |
| **Waitlist**         | ユーザーが自発的に参加希望を送信し、管理者の承認を経て会員登録に進める招待方式（Clerk Waitlist signup mode）。詳細は`domain/membership.md`参照                   |
| **個人会員**         | Clerkの個人Userとして登録した会員。会員自身がランク・月次上限を持つ                                                                                              |
| **法人会員（組織）** | ClerkのOrganizationとして登録した会員。所属する一般担当者は個人としてのランクを持たず、組織のランク・月次上限を共有する                                          |
| **停止**             | 管理者がアクセスをブロックし課金を一時停止する、可逆的な操作                                                                                                     |
| **強制退会**         | 管理者権限で会員を退会させる、不可逆な操作                                                                                                                       |

## 招待

| 用語           | 定義                                                     |
| -------------- | -------------------------------------------------------- |
| **招待コード** | 会員登録に必要なコード。招待コードがなければ登録できない |
| **招待権限**   | 他の人を招待できる権限。会員ごとに付与・制限される       |
| **招待上限数** | 1人の会員が招待できる人数の上限                          |
| **招待済み数** | その会員がすでに招待した人数                             |

---

## 商品・カタログ

| 用語                       | 定義                                                                                                         |
| -------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **コンシェルジュカタログ** | このサービスで閲覧・購入できる商品の一覧。全ランク共通でアクセスできる                                       |
| **手配リクエスト**         | カタログ掲載外の商品の取り寄せ依頼機能。全ランク共通で利用できる                                             |
| **ブランド**               | このEC内で取り扱う商品メーカー・ブランドそのもの（例：ReFa）                                                 |
| **卸売価格**               | 会員が購入できる価格。市場価格より低い仕入れ価格（掛け率はランク・商品ごとに異なる。`service-spec.md` 参照） |
| **ランク制限商品**         | 特定ランク以上の会員のみ閲覧・購入できる商品                                                                 |
| **在庫数**                 | 実際に販売できる商品の数量                                                                                   |
| **ソフト予約**             | カートに追加した時点で確保される仮の在庫。決済完了で確定、キャンセルで解放される                             |
| **カテゴリ**               | 商品の分類（例：アパレル・アクセサリー等）                                                                   |

## 月間仕入れ

| 用語               | 定義                                                                   |
| ------------------ | ---------------------------------------------------------------------- |
| **月間仕入れ上限** | 1ヶ月間に購入できる金額の上限。ランクごとに設定される                  |
| **仕入れ残枠**     | 当月の月間仕入れ上限から、すでに購入した金額を引いた残り               |
| **月次リセット**   | 毎月決まった日に仕入れ残枠がリセットされること（リセット日は別途定義） |

---

## カート・注文・決済

| 用語                        | 定義                                                       |
| --------------------------- | ---------------------------------------------------------- |
| **カート**                  | 購入前に商品を一時的に保存する場所                         |
| **注文**                    | カートの内容を確定して決済手続きを開始した記録             |
| **注文明細**                | 注文に含まれる商品ごとの内訳（商品名・数量・購入時の単価） |
| **決済**                    | Stripe を通じて行われる支払い処理                          |
| **注文ステータス**          | 注文の現在の状態。以下の4種類がある                        |
| └ `pending`（保留中）       | 決済手続き中。まだ支払いが完了していない状態               |
| └ `paid`（決済済み）        | 支払いが完了した状態                                       |
| └ `shipped`（発送済み）     | 商品が発送された状態                                       |
| └ `cancelled`（キャンセル） | 決済がキャンセルまたは失敗した状態                         |

## サブスクリプション

| 用語                     | 定義                                                                                                                                                                  |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **サブスクリプション**   | ランクに紐づく月額課金契約。Stripe で管理される                                                                                                                       |
| **プラン変更**           | ランクのアップグレード・ダウングレードのこと。Stripe のサブスクリプションが更新される                                                                                 |
| **billing_anchor_day**   | 月次仕入れ上限の集計期間の起点となる「日」（1〜28）。新規登録日を初期値とし、アップグレード時に今日へリセットされる                                                   |
| **ダウングレード予約**   | ダウングレードを申請した時点ではランクは変わらず、現在の請求期間が終わるまで現ランクを維持し、期末に自動で切り替わる予約状態（`domain/subscription-billing.md` 参照） |
| **支払い済み最高ランク** | これまでに初期費用を支払った中で最も高いランク。退会後も保持し、再入会時の初期費用免除判定に使う                                                                      |
| **ランク変更履歴**       | 「いつ・誰の操作で・どのランクからどのランクに変わったか」を追記専用で記録するログ                                                                                    |

## 付加機能（ランク別）

> ⚠️ **要確認**: 以下は旧5ランクモデル時代の記述。現行 `service-spec.md` にはこれらの付加機能に関する記載がなく、新7ランクモデルでどのランクにどの機能が付くか（あるいは廃止されたか）が未確定。`service-spec.md` 側に追記するか本セクションを削除するか判断が必要。

| 用語                       | 定義                                                                       |
| -------------------------- | -------------------------------------------------------------------------- |
| **専任担当者サポート**     | 旧 Entry 以上のランクに付属していた、専任スタッフによるサポート            |
| **優先対応**               | 旧 Standard 以上のランクに付属していた、問い合わせへの優先的な対応         |
| **専用ライン**             | 旧 Pro 以上のランクに付属していた、専用の連絡先（電話・チャット等）        |
| **月次仕入れレポート**     | 旧 Pro 以上のランクに付属していた、月ごとの仕入れ実績レポート              |
| **カスタムレポート・分析** | 旧 Enterprise ランクに付属していた、個別にカスタマイズされたレポートと分析 |

`SLA 対応` は現行仕様でも有効（`service-spec.md` より）:

| 用語         | 定義                                                            |
| ------------ | --------------------------------------------------------------- |
| **SLA 対応** | ENTERPRISE ランクに付属する、サービスレベル保証契約に基づく対応 |

## 運営者権限（Admin RBAC）

| 用語             | 定義                                                                                                                   |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **運営スタッフ** | 運営組織に所属するClerkアカウント。会員（顧客）とは別の集約として管理される。3ロール（管理者・請求顧客担当・調達担当） |
| **運営組織**     | 御社（運営会社）自身を表すClerk Organization。顧客企業の`organizations`（法人会員）とは別の概念。現時点では1つのみ     |
| **ロールキー**   | Clerk Organizationsのカスタムロール機能で定義される識別子（例: `org:order_manager`）                                   |
| **カスタム権限** | Clerkのカスタム権限機能で定義される、ロールに紐づく個別の操作許可（例: `org:orders:manage`）                           |

詳細は `docs/domain/admin-rbac.md` を参照。

## 発注管理（Procurement）

| 用語                  | 定義                                                                                                                |
| --------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **発注タスク**        | 運営スタッフが一次卸業者へ発注する作業単位。複数の顧客注文にまたがる同一商品の明細をまとめて1つの発注タスクにできる |
| **対応待ちキュー**    | まだどの発注タスクにも入っていない、発注担当が次に着手すべき注文明細の集合                                          |
| **着手（`claimed`）** | あるスタッフが発注タスクに対応中であることを宣言し、他のスタッフによる重複対応を防ぐ状態                            |
| **一次卸業者**        | 商品を実際に仕入れる先。API連携は存在せず、発注行為そのものは人手（電話・仕入れサイト）で行う                       |
| **発注期限**          | 注文に含まれる商品を、配送SLAに間に合わせるためにいつまでに一次卸業者へ発注すべきかの期限                           |

詳細は `docs/domain/procurement.md` を参照。

## 環境・開発プロセス

| 用語                 | 定義                                                                                           |
| -------------------- | ---------------------------------------------------------------------------------------------- |
| **ステージング環境** | 本番公開前に動作確認するためのテスト用環境。`develop` ブランチの最新状態が自動でデプロイされる |
| **本番環境**         | 実際の顧客が使う公開環境。`main` ブランチへのマージ後に自動でデプロイされる                    |
| **スプリント**       | 一定期間（1〜2週間）を1サイクルとして機能を開発・リリースするアジャイル開発の単位              |
| **バックログ**       | 今後開発する機能・タスクの一覧。Linear で管理される                                            |
| **デプロイ**         | 作成したコードを環境に反映させること                                                           |
