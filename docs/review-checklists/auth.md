# 認証・認可

ルート保護（`src/middleware.ts`）・ログインユーザーの取得（`src/lib/auth/`）・RLSを迂回するservice roleクライアント（`src/lib/supabase/server-admin.ts`）の変更。漏れると、ログインしていない人や他の会員・権限の無い運営者が操作できてしまう。

- [ ] 保護の対象から外れるルートが無いか（matcherやパスの判定の変更で、会員・管理画面・APIが公開されていないか）

- [ ] service roleクライアントの使い道（RLSを迂回するため、使う側で「誰の行か」を必ず絞っているか。クライアントのコードから読み込まれていないか）
- [ ] 未ログイン・別の会員・権限の無い運営者で試したときに拒否されることをテストしているか
