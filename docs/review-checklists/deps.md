# 依存の追加・更新

`package.json`・`pnpm-lock.yaml` の変更。依存はアプリと同じ権限で動くため、追加・更新はコードを足すのと同じ重さがある。スクリプトだけの変更も、パスでは区別できないため対象になる。

## 確認観点

- [ ] 追加する依存が本当に必要か（既存の依存・Node.jsの標準で足りないか）
- [ ] 提供元の信頼性（メンテナンスされているか・ダウンロード数・名前の似た別パッケージではないか）
- [ ] `dependencies` と `devDependencies` の区別（本番のバンドルに入るか。Cloudflare Workersで動くか）
- [ ] メジャーバージョンの更新なら、破壊的変更の一覧を確認したか
- [ ] `pnpm-lock.yaml` に、`package.json` の変更と関係の無い大きな更新が混ざっていないか
- [ ] `scripts` の変更で、`task check` やCIで動くコマンドの中身が変わっていないか
