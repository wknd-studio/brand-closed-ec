# 決済・注文・金額計算

Stripe・注文の確定・取消・金額の計算（`src/use-cases/` の注文系・`src/domain/` の金額・`src/infrastructure/stripe/` 等）の変更。誤ると、請求額の誤り・二重課金・未払いの注文の確定につながる。

## 確認観点

- [ ] 端数（税込・税抜の変換や割引で、どこで・どの方向に丸めるか。明細の合計と合計金額がずれないか）
- [ ] 税（税率・軽減税率の扱い、インボイスの記載項目と一致するか）
- [ ] 上限・下限の境界（月の購入上限・最小数量・0円・上限ちょうどのときの扱い）
- [ ] 金額をクライアントから受け取っていないか（サーバー側で商品・数量から計算し直しているか）
- [ ] 状態の遷移（支払い済み・取消済みの注文を、もう一度確定・取消できてしまわないか。Stripeの状態と注文の状態がずれたときにどうなるか）
- [ ] 二重実行（ボタンの連打・再送で、注文やStripeのセッション・課金が二重に作られないか）
- [ ] 境界の値と失敗の分岐をユニットテストで確かめているか
